Privacidade e LGPD

Tratamos dados pessoais para operar contas, partidas, moderação e prevenção a fraude, nos termos da Lei nº 13.709/2018 (LGPD).

Dados coletados

  • Cadastro: e-mail, nick, hash de senha
  • Operação: IP, registros de partida, chat de sala, preferências
  • KYC (quando solicitado): imagem/documento para análise manual de saque

Direitos

Você pode solicitar acesso, correção ou exclusão de dados via suporte, observados prazos legais e retenção necessária para disputas e auditoria.

Retenção e segurança

Sessões expiram; backups off-box podem ser configurados pelo operador (BACKUP_INTERVAL_MS / npm run db:offbox).
