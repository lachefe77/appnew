# Sorte — Identidade visual

Logo profissional da marca **Sorte**, com símbolo de baralho / naipes (espadas, copas, ouros, paus).

## Paleta

| Cor | Hex | Uso |
|---|---|---|
| Carvão | `#0a0a0c` | Fundo escuro / contraste |
| Ouro | `#d4a017` | Símbolo, destaques premium |
| Ouro claro | `#f0d078` | Brilho / traços |
| Carmesim | `#9b1b2e` | Detalhe de copas |
| Marfim | `#f5ecd7` / `#f7f4ee` | Texto claro / fundo claro |

## Arquivos

| Arquivo | Uso |
|---|---|
| `logo-horizontal-dark.png` / `.svg` | Logo completa (fundo escuro) — site, header, apresentação |
| `logo-horizontal-light.png` / `.svg` | Logo completa (fundo claro) — documentos, impressão |
| `icon-app.png` | Ícone quadrado do app / extensão |
| `avatar.png` | Avatar circular — redes sociais |
| `symbol.svg` | Marca só (cartas sobrepostas) — favicon, watermark |
| `symbol-suits.png` / `.svg` | Trevo com os 4 naipes |

## Conceito

Duas cartas de baralho sobrepostas (espadas + copas) evocam **sorte** e jogo, com acabamento luxury (ouro + carvão), sem visual “cassino genérico” exagerado.
