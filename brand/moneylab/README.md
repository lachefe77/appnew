# MoneyLab Brand Assets

Professional logo system for **MoneyLab** — fintech / financial lab identity.

## Concept

A laboratory flask shaped as an **M**, with an ascending market chart inside. The mark blends science + finance: experimentation, growth, and precision.

## Color Palette

| Token   | Hex       | Use                          |
|---------|-----------|------------------------------|
| Navy    | `#0B1F33` | Mark body, "Money"           |
| Green   | `#00C853` | Chart, growth arrow, "Lab"   |
| Gold    | `#C9A227` | Flask rim accent             |
| White   | `#FFFFFF` | Background / cavity          |
